# Blocks

A block texture changes how a vanilla block looks. You pick the block it
replaces (stone, oak planks, diamond ore) and every copy of that block in the
world shows your art instead.

A resource pack can only change how existing blocks look. It can't add a new
kind of block. If you want something with its own shape, make a
[model](/models) instead.

## Making one

Open a pack, press **Add asset** and pick **Block**. There are three ways in:

- **Generate**: describe it and the AI draws it.
- **Blank**: opens the editor with an empty canvas, or a copy of the vanilla
  block to repaint.
- **Upload**: use a PNG you already have.

All three ask for the **Block to replace**. Textures that only skin a custom
model are made from inside the model editor instead, and replace nothing.

  How to write a prompt that gives you something worth finishing.
</Card>

### Size

| Size | When to use it |
| --- | --- |
| **16×16** | Vanilla's own resolution, and the default. Sits naturally next to vanilla blocks |
| **32×32**, **64×64** | "HD" packs. More room for detail, and four or sixteen times the pixels to finish |
| **Custom** | Any square size, up to 256 when drawing from blank |

<Callout type="note" title="Generated blocks are drawn at 16×16">
  The AI always paints a block at 16×16, vanilla's resolution. If you pick a
  bigger size, that drawing is scaled up without blurring, so it looks the same
  in game. Use the extra pixels to add detail by hand.
</Callout>

Once you have a draft, the block's page has **Regenerate** (same prompt, new
attempt) and **Edit with AI** (describe one change, keep the rest).

## The pixel editor

The pixel editor opens full screen from a block, and from the model editor
when you want to paint a face properly.

### Tools

| Tool | Key | Notes |
| --- | --- | --- |
| Pencil | `B` | Paints the active colour |
| Eraser | `E` | Paints transparency, not white |
| Fill | `F` | **Connected** fills touching pixels; **Global** fills every pixel of that colour. **Tolerance** sets how close a colour has to be |
| Pick colour | `I` | Samples a pixel into the active colour |
| Line | `L` | Drag from one point to another |
| Rectangle | `R` | Tick **Filled shape** for a solid one |
| Ellipse | | Filled or outline, like the rectangle |
| Select | `S` | Select a region to move, copy (`Ctrl+C`), paste (`Ctrl+V`) or delete |
| Text | `T` | Stamps words in Minecraft's font. They become ordinary pixels |

Undo and redo are `Ctrl+Z` and `Ctrl+Y`, and cover layers too.

The tool options panel also has:

- **Brush size**, 1 to 8 pixels. Line and rectangle use it too.
- **Alpha** lock, which only paints over pixels that already have colour.
- **Mirror X** and **Mirror Y**, which paint the mirrored copy of every stroke.
  Both together give four-way symmetry.

<Callout type="tip">
  The eraser makes pixels see-through, not white. On a block that should be
  solid, a transparent pixel shows as a hole, so fill gaps with colour.
</Callout>

### Layers

Layers are listed topmost first and flattened when the texture is saved. You
can rename them (double-click), reorder, hide and delete them, and nudge or
rotate a layer's contents with the arrows under the list.

A good habit: keep the AI's draft on the bottom layer and paint your fixes on a
layer above it, so you can always go back.

The editor saves when you press **Save**. **Export PNG** downloads the image.

## Per-face blocks

A full-cube block doesn't have to look the same on every side. On the block's
page, the **Faces** card shows each face, and each can have its own texture.
Click a face to generate it, edit it, or reset it to the base texture.

Blocks that vanilla already textures in parts (logs, sandstone, deepslate)
show their own parts instead, such as **Top**, **Bottom** and **Sides**.
Blocks that aren't simple cubes (stairs, flowers, doors) don't have a Faces
card; retexture them as a single texture.

**Edit** on a block opens the block editor: a **Block** tab with the block in
3D, plus one tab per face. On the Block tab you paint directly on the cube
(drag to paint, drag empty space to orbit). Double-click a face, or click its
tab, to open it in the pixel editor. A face's menu has **Apply to all faces**,
which copies it onto every side. The block editor saves as you go.

<Callout type="warning" title="Some blocks rotate randomly when placed">
  Stone, dirt, sand, netherrack and a few other natural blocks are given a
  random rotation each time they're placed, to hide repetition. Their top and
  bottom are safe, but a distinct north, south, east or west face points a
  different way on each block. Building blocks (planks, wool, concrete,
  bricks) don't rotate.
</Callout>

## Seeing it in game

[Sync](/testing/plugin) the pack to a linked player and every copy of that
block changes at once. **Give in-game** on the block's page hands you some to
place.

Blocks are worth judging in the world rather than in the editor: a texture that
looks great zoomed in can turn into noise in a wall of itself.

<Callout type="tip">
  On [our test server](/testing/test-server), `/floor <block>`, `/time` and
  `/weather` change what your block sits against. Try it on grass, on white
  concrete and at night.
</Callout>

## Exporting

In the exported `.zip`, a block texture is a PNG at
`assets/minecraft/textures/block/<name>.png`, named after the vanilla block it
replaces. Minecraft already looks there, so a plain reskin needs no other
files.

A per-face block also gets a block model under `assets/minecraft/models/block/`
that maps each face to its texture. Studio writes it from the Faces card.

The size you worked at is the size in the file. A 64×64 pack installs the same
way as a 16×16 one.

## On Bedrock

Block reskins carry over to the Bedrock `.mcpack`, renamed where Bedrock calls
a block something else (`oak_planks` is `planks_oak`, `white_wool` is
`wool_colored_white`). Per-face blocks carry only their base texture.
