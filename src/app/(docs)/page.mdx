# ResourcePack AI

ResourcePack AI is a web app for making Minecraft resource packs. A resource
pack is the folder of textures, models and sounds that changes how the game
looks and sounds. You describe what you want in plain words, the AI makes a
first version, you finish it in the editors, and then you try it in Minecraft
on a real server.

The app is called **Studio**, and it runs in your browser at
[studio.resourcepack.ai](https://studio.resourcepack.ai). There's nothing to
install.

## What a pack can hold

Every pack has a tab for each of these. All of them can be generated, started
blank, and most can be uploaded from files you already have.

  </Card>
  <Card title="Vehicles" href="/vehicles" icon="gauge">
    Models people can ride: seats, handling, sounds and effects.
  </Card>
  <Card title="Blocks" href="/blocks" icon="blocks">

  <Card title="Items" href="/items" icon="item">
    Flat item sprites or 3D items, for the hand and the inventory.
  </Card>
  <Card title="Armour" href="/armor" icon="wrench">

  </Card>
  <Card title="GUIs" href="/guis" icon="gui">
    Restyled chests, furnaces, the inventory and other screens.
  </Card>
  <Card title="Dialogs" href="/dialogs" icon="gui">
    Screens a server opens over the game, with real buttons.
  </Card>
  <Card title="HUD" href="/hud" icon="image">

Models can also be **animated**, and players can have **emotes**: a wave, a
dance, or a whole set of movements they wear while they walk around. See
[Animations](/animations) and [Emotes in RP Engine](/rp-engine/emotes).

## Testing it in Minecraft

You don't have to export anything to see your work in game. Join our test
server (<ServerAddress />, Java or Bedrock), link your account once with
`/permlink`, and from then on the **Sync** button in Studio sends the pack
straight to you while you stand there. The [Quickstart](/quickstart) walks
through it.

Some things a resource pack can't do by itself: place a model and have it
animate, drive a vehicle, play an emote, open a custom screen. Those need
[RP Engine](/testing/plugin), our server plugin. The test server already runs
it, and you can install it on your own Paper or Spigot server.

<Callout type="note" title="Java and Bedrock">
  Bedrock players can join, link and receive packs too. Bedrock only accepts
  a pack while joining, so applying one disconnects you and reconnects you
  automatically, which takes a few seconds.
</Callout>

## When it's finished

A pack you [export](/exporting) is an ordinary resource pack: the same
folders, JSON and PNGs the game expects. It works anywhere a pack works,
including on a server that has nothing of ours installed. You can export a
Java `.zip`, a Bedrock `.mcpack`, or content for server plugins such as
ItemsAdder, Nexo, Oraxen, CraftEngine and ModelEngine.
