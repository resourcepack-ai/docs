# ResourcePack AI

ResourcePack AI makes Minecraft resource packs. A resource pack is the set of
textures, models and sounds that changes how the game looks and sounds: a new
look for stone, a sword with a custom model, a restyled inventory.

You do it in **Studio**, a web app at
[studio.resourcepack.ai](https://studio.resourcepack.ai). There's nothing to
install. It works like this:

1. **Describe** what you want ("weathered copper roof tiles") and the AI makes
   a first version. Generating costs **AI Credits**, the app's currency; a
   free account gets 50 a month.
2. **Finish it** in the editors: a pixel editor for textures, a 3D editor for
   models, and editors for sounds, screens and the rest.
3. **Try it in Minecraft.** Join our free test server, press **Sync** in
   Studio, and the pack loads on your game in seconds.
4. **Export** it when it's done, as an ordinary pack file anyone can use.

## What a pack can hold

A **pack** is one project: everything for one server or one look. Each thing
in it is an **asset** (one Block, one Model, one Sound), and each kind has its
own tab. All of them can be generated or started blank, and most can be
uploaded from files you already have.

## Testing it in Minecraft

You don't have to export anything to see your work in game. Join our test
server (<ServerAddress />, Java or Bedrock) and link your Minecraft account
once with `/permlink`. From then on, the **Sync** button in Studio sends the
pack to you while you stand there. Only you see it. The
[Quickstart](/quickstart) walks through it.

## The plugins

A resource pack can only change how things look. Some things need a plugin on
the server too: placing a model that animates, driving a Vehicle, playing an
Emote, opening a custom screen.

- **[RP Engine](/testing/plugin)** is our main plugin, and the one Studio is
  built around. The test server already runs it, and you can install it on
  your own Paper, Spigot or Folia server, which also lets you sync to it.
- **[Our other plugins](/plugins)** each do one job and don't need RP Engine:
  MC GUI for menus and shops written in HTML, Dialog Engine for Minecraft's own
  dialog menus, 3D Engine for real 3D models from `.glb` or `.obj` files.

<Callout type="note" title="Java and Bedrock">
  Bedrock players can join, link and receive packs too. Bedrock only accepts
  a pack while joining, so they're disconnected and reconnected for a few
  seconds each time. See [Bedrock and Geyser](/bedrock).
</Callout>

## When it's finished

An [exported](/exporting) pack is an ordinary resource pack, with the same
folders, JSON and PNGs the game expects. It works anywhere a pack works,
including a server with nothing of ours installed. You can export a Java
`.zip`, a Bedrock `.mcpack`, or content for other server plugins such as
ItemsAdder, Nexo, Oraxen, CraftEngine and Model Engine.
