# Importing

Importing turns a Java resource pack `.zip` you already have into a pack in
Studio, so you can edit its textures, models, icons, GUIs and sounds here. Use
it to carry on with an old pack, or to restyle somebody's pack you have the
rights to.

Import always **creates a new pack**; it never merges into one you already
have. To get pieces of it into another pack afterwards, see
[Moving assets between packs](/moving-assets).

## Importing a pack

<Steps>
  <Step title="Press Import and pick the zip">
    **Import** is next to **New pack** on the dashboard. The zip is read
    **in your browser** and nothing is uploaded yet, so even a large pack is
    quick.
  </Step>
  <Step title="Review what was found">
    The review screen lists what will come in and what won't, file by file,
    with the reason for each file left out.
  </Step>
  <Step title="Approve it">
    Only now does anything upload. The pack is created and fills in. If you
    cancel partway, Studio asks whether to keep or delete what has already
    arrived.
  </Step>
</Steps>

## What comes in

- **Block and item textures**, for anything the game has a texture for.
- **Block models**, with their textures, including faces that use vanilla
  textures.
- **Icons**, when the pack's font files say where each one is on its sheet.
  Up to 256 per import.
- **GUI sheets** for the screens Studio knows (chests, furnaces, the inventory
  and so on).
- **Sounds**, when the pack's `sounds.json` names them, since the name decides
  whether a sound replaces a vanilla one or is new. Up to 64 per import.

**Packs with versions inside them** (`overlays` folders for several Minecraft
versions) come in as the version the pack itself declares. The other versions'
files are set aside and listed.

## What can't come in

Reported, never silently dropped:

- **Entity, painting and particle sheets.** Nothing in the pack says how to
  cut them up.
- **Core shaders.**
- **Blockstate and item definition files.** Studio writes those itself when
  it exports.
- **Audio Minecraft can't play properly.** Anything that isn't mono Ogg
  Vorbis: Ogg *Opus* files (same `.ogg` extension, but silent in game),
  stereo `.ogg` files (which don't sound like they come from a place), and
  other formats.
- **OptiFine extensions.**

## Importing a pack you exported from Studio

Most of it comes back: shapes, textures and sounds. What doesn't, yet: a model's animations, bones and
display settings come back as plain geometry, and per-face block textures
return as ordinary model textures. Keep the original pack around rather than
treating export-import as a backup loop.
