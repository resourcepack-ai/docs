# Custom fonts

A font asset is a **bitmap glyph** bound to a character. Type that character
anywhere Minecraft renders text — chat, signs, books, item names, holograms —
and your image appears inline. It's how server icons, custom emotes and inline
UI symbols are done.

## Sizes

Three presets, plus a custom height up to 256. The choice is about line height
rather than quality:

| Size | Behaviour |
| --- | --- |
| **8px** | Sits flush inside one line of text. The only size guaranteed not to spill |
| **16px** | Deliberately oversized — overlaps the lines above and below. The default |
| **32px** | Much more so |

Minecraft's line pitch is about 9 pixels and the renderer does **not** reflow
line spacing for taller glyphs. So 16 and 32 aren't bugs to be worked around;
they're the Discord-style "big emoji" effect, and they overlap on purpose.

<Callout type="tip">
  If a glyph is meant to read as part of a sentence — a currency symbol, a
  status dot, a key icon — use 8px. Reach for the larger sizes when the glyph
  *is* the message.
</Callout>

## Characters

Glyphs are assigned to codepoints in Unicode's **Private Use Area**
(`U+E000`–`U+F8FF`) — the block reserved for exactly this, so your glyph can
never collide with a real character someone might type.

Practically: you copy the character out of studio and paste it wherever you
need it. It looks like a blank box everywhere except in a client with your pack
loaded, which is expected.

<Callout type="tip">
  On [our test server](/testing/test-server), `/sidebar`, `/title`,
  `/actionbar` and `/bossbar` take arbitrary text — paste a glyph into one to
  see how it sits against real UI text rather than only in chat.
</Callout>

## Making one

Same three routes as everything else: describe it and let the AI draft it,
upload a PNG, or draw it from blank in the pixel editor. Source art is capped
at 256×256 before it's fitted to the size you chose.

<Callout type="note">
  Glyphs are pixel art at small sizes, and legibility falls off a cliff below
  about 6 pixels of actual detail. Silhouette first, detail second — the same
  rule as a 16×16 block texture.
</Callout>
