# Writing docs

This page is the style guide and the test page at once: everything below is
rendered by the same components a real page uses, so if something breaks, it
breaks here first.

## Adding a page

Two steps, and only two:

<Steps>
  <Step title="Create the file">
    ```
    src/app/(docs)/guides/my-page/page.mdx
    ```

    The folder path is the URL. Start the file with a `metadata` export and
    an `h1`:

    ```mdx title="page.mdx"
    export const metadata = {
      title: "My page",
      description: "One sentence, used for search and link previews.",
    };

    # My page
    ```
  </Step>
  <Step title="Add it to the nav">
    Open `src/lib/nav.ts` and add an entry. That one list drives the
    sidebar, the ⌘K search index, and the prev/next links at the foot of
    every page — a page that isn't in it is invisible.

    ```ts title="src/lib/nav.ts"
    {
      title: "My page",
      href: "/guides/my-page",
      description: "Shown under the title in search results.",
      keywords: ["extra", "search", "terms"],
    }
    ```
  </Step>
</Steps>

<Callout type="tip">
  The group label above each page title, the "On this page" rail, and the
  pager are all automatic. Never write them into a page by hand.
</Callout>

## Callouts

Four types. If a note needs a fifth, it probably wants to be a paragraph.

<Callout type="note" title="Note">
  Context the reader needs but wouldn't have looked for.
</Callout>

<Callout type="tip" title="Tip">
  A shortcut, or the thing you'd say over their shoulder.
</Callout>

<Callout type="warning" title="Warning">
  Something that will cost them time if they get it wrong.
</Callout>

<Callout type="danger" title="Danger">
  Something that destroys work. Use this almost never.
</Callout>

```mdx
<Callout type="warning" title="Codes expire">
  A pairing code is single-use and short-lived.
</Callout>
```

## Code

Fenced blocks are highlighted at build time and get a copy button on hover.

```ts title="src/lib/nav.ts" showLineNumbers {3-4}
export const nav: NavGroup[] = [
  {
    title: "Getting started",
    items: [{ title: "Introduction", href: "/" }],
  },
];
```

The fence's info string carries the options:

| Written after the language | Does |
| --- | --- |
| `title="file.ts"` | Adds the filename bar above the block |
| `showLineNumbers` | Numbers the lines |
| `{3-4}` or `{1,5}` | Highlights those lines |

Inline code like `/link <code>` uses single backticks.

## Everything else

Plain markdown works as you'd expect — **bold**, *italic*, [links](/), lists,
tables, and rules:

- A list item
- Another one, with `inline code`
  - And a nested one

> A blockquote, for quoting someone rather than for emphasis.

If you need something that isn't here, add it to
