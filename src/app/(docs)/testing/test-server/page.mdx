# Our test server

Our test server is the quickest way to see a pack in Minecraft. There's
nothing to install and no server of your own to run.

```
play.resourcepack.ai
```

Join on Minecraft Java or Bedrock. It's the same address and the same worlds,
so Java and Bedrock players see each other.

## Where to build

<CardGroup>
  <Card title="The shared sandbox" icon="blocks">
    In front of you in the lobby. Everyone shares it, it **wipes every hour**,
    and each player can leave up to 10 models standing in it.
  </Card>
  <Card title="Your own sandbox" icon="boxes">
    Through the portal, or `/sandbox` from anywhere. Private, and **kept
    between visits**, for anything you want to still be there tomorrow.
  </Card>
</CardGroup>

Your sandbox is tied to your account, so you get the same one every time.
It's removed after **a week without a visit**; any visit resets the clock.

## Commands

| Command | What it does |
| --- | --- |
| `/help` | The in-game list of all of this |
| `/links` | The Discord and Studio links, clickable in chat |
| `/invite <player>` | Let someone into your sandbox |
| `/kick <player>` | Remove them again |
| `/floor <block>` | Change your sandbox floor material |
| `/time <time>` | Set the time in your sandbox |
| `/weather <clear\|rain\|thunder>` | Set the weather in your sandbox |
| `/reset` | Wipe your sandbox back to empty |
| `/fly` | Toggle flight when your rank has the `rpai.fly` permission |
| `/sandbox` (or `/private`) | Straight to your own sandbox, wherever you are |
| `/shared` (or `/plot`) | Straight to the shared sandbox in the lobby |
| `/leave` | Leave the sandbox you're in |
| `/hub`, `/lobby`, `/spawn` | Back to the lobby |
| `/cinematic` | Play the server's intro flythrough |

<Callout type="tip">
  Use `/floor`, `/time` and `/weather` to judge a texture against white
  concrete, grass and deepslate, and once at night. It shows in half a minute
  whether it works where people will actually build with it.
</Callout>

### Seeing a pack where players will actually see it

These put your own text and items where Minecraft draws them, which is the way
to check a custom icon, a font or a model worn on the head:

| Command | What it does |
| --- | --- |
| `/head` | Wear the item you're holding, to judge the head display slot. Run it empty-handed to take it off. Only works where you can build |
| `/sit` | Sit down where you're standing |
| `/sidebar <title> \| <line> \| ...` | Put your own text on the scoreboard sidebar |
| `/actionbar <text>` | Put your own text on the action bar |
| `/title <title> \| <subtitle>` | Show yourself a title |
| `/bossbar <text> \| <colour> \| <style> \| <0.0-1.0>` | Put your own text on a boss bar |

## Your in-game rank

Once your Minecraft account is linked, the server gives you an in-game rank
from your ResourcePack AI account. A Creator or Studio subscription shows as
the **Creator** or **Studio** rank. **Early Access** and **Supporter** are
badges that sit alongside your plan rank. Your rank colours your name.
Starter has no rank.

## Linking your account

Do this once. It's what lets **Sync** find you on the server, and what gives
you the rank above.

<Steps>
  <Step title="Get a code from the Studio">
    On your [account page](https://studio.resourcepack.ai/account), under
    **Minecraft account**, press **Get link code**. It's good for ten
    minutes.
  </Step>
  <Step title="Run it in game">
    ```
    /permlink 48213097
    ```
    The account page updates on its own once it works.
  </Step>
</Steps>

## Loading your pack

Once you're linked there's no per-pack setup: press **Sync** on any pack while
you're on the server and it arrives. On Java it loads where you stand; on
Bedrock you're briefly disconnected and reconnected.

<Callout type="note">
  The pack goes to **you**, not to the whole server. Someone standing next to
  you won't see it.
</Callout>

## Getting what you made in front of you

Reskins are live as soon as the pack loads: every reskinned block, item or
sound in the world uses your version. For everything else, the asset's page in
Studio has a button that does it for you while you're on the server:

| Asset | Button | What happens in game |
| --- | --- | --- |
| Model | **Give in-game** | The model's item lands in your hand. Right-click a block to place it; punch it to pick it back up |
| Block | **Give in-game** | You're handed the vanilla block it reskins |
| Item | **Give in-game** | You're handed the item, tagged so it wears your sprite |
| GUI | **Open in-game** | The reskinned screen opens in front of you |
| Icon | **Send in-game** | The glyph arrives in your chat |
| Sound | **Play in-game** | The event plays where you're standing |

Each button sits next to the matching command, so you can copy that instead to
type it yourself or use it on your own server.
