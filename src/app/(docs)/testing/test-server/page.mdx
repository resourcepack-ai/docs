# Our test server

The zero-setup way to see a pack in Minecraft. Nothing to install, no plugin,
no server of your own.

```
play.resourcepack.ai
```

Join on Minecraft Java **or** Bedrock — same address, same worlds, and you'll
see each other. You'll land in the lobby.

## Where to build

<CardGroup>
  <Card title="The shared plot" icon="blocks">
    In front of you in the lobby. Everyone's, and it **wipes every hour** —
    for a quick look at one block.
  </Card>
  <Card title="Your own world" icon="boxes">
    Through the portal. Private, and **kept between visits** — for anything
    you want to still be there tomorrow.
  </Card>
</CardGroup>

Your sandbox world is tied to your account, so you get the same one every
time. It's removed only after a long stretch with no visits.

## Commands

| Command | Does |
| --- | --- |
| `/help` | The in-game list of all of this |
| `/invite <player>` | Let someone into your sandbox |
| `/kick <player>` | Remove them again |
| `/floor <block>` | Change your sandbox floor material |
| `/time <time>` | Set the time in your sandbox |
| `/weather <clear\|rain\|thunder>` | Set the weather in your sandbox |
| `/reset` | Wipe your sandbox back to empty |
| `/fly` | Toggle flight when your rank has the `rpai.fly` permission |
| `/leave` | Leave the sandbox you're in |
| `/hub`, `/lobby`, `/spawn` | Back to the lobby |

<Callout type="tip">
  `/floor`, `/time` and `/weather` are more useful than they look. Judging a
  texture against white concrete, then grass, then deepslate — and once at
  night — tells you in half a minute whether it reads in the places people
  will actually build with it.
</Callout>

### Seeing a pack where players will actually see it

A pack isn't only blocks. These put your own text and items into the places
Minecraft renders them, which is the only honest way to check a custom font or
a model's head slot:

| Command | Does |
| --- | --- |
| `/head` | Wear the item you're holding, to judge the head display slot. Run it empty-handed to take it off |
| `/sit` | Sit down where you're standing |
| `/sidebar <title> \| <line> \| ...` | Put your own text on the scoreboard sidebar |
| `/actionbar <text>` | Put your own text on the action bar |
| `/title <title> \| <subtitle>` | Show yourself a title |
| `/bossbar <text> \| <colour> \| <style> \| <0.0-1.0>` | Put your own text on a boss bar |

Each of them clears when run with no arguments. Paste a [custom font
glyph](/editors/fonts) into any of them to see how it sits against real UI
text.

`/head` only puts something on inside your own sandbox or the shared plot —
the same places you can build. Taking it off works anywhere, so walking back
to the lobby wearing something is never a dead end.

## Your in-game rank

Once your Minecraft account is linked and verified, the test server mirrors
your ResourcePack AI account into LuckPerms. Creator and Studio subscriptions
use the `creator` and `studio` ranks. Early Access and Supporter use the `ea`
and `supporter` badges, which stack above your plan rank instead of replacing
it. Your resolved rank colour also takes precedence for your player name.
Starter has no synced rank.

## Loading your pack

The test server also runs the linking plugin, so getting your pack onto your
client is the same flow as on your own server:

<Steps>
  <Step title="Get a code from studio">
    Open the live-test panel for the pack. It shows a `/link` command with an
    8-digit code.
  </Step>
  <Step title="Run it in game">
    ```
    /link 48213097
    ```
  </Step>
  <Step title="Push">
    Studio shows you as connected. Pushing sends the pack straight to your
    client — nothing to download or upload. On Java it swaps in where you
    stand; on Bedrock you're briefly bounced out and back in.
  </Step>
</Steps>

Full detail on the linking flow, including how to run it on a server you own,
is in [Your own server](/testing/your-server).

<Callout type="note">
  The pairing is to **you**, not to the server. Someone standing next to you
  won't see your pack unless they link their own.
</Callout>
