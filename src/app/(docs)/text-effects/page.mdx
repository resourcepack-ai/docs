# Text Effects

A Text Effect makes text move, burn, shine or fill with water: letters that
bob on a wave, a rainbow that scrolls, pixel flames licking up off every
letter. It works on any text the game draws flat on the screen: chat, item
names and lore, titles, scoreboards and menus.

![Text effects made in Studio](/images/text-effects.gif)

## Making one

Press **Add asset** and pick the **Text Effect** tab. Then either:

- **Describe the look** ("molten gold", "frozen solid", "glitching"). It costs
  about 20 credits and takes a few minutes.
- **Pick one of the 32 presets.** Free, and ready at once.

Either way, you can ask for changes afterwards with **Edit with AI** on its
page.

The page plays the effect live on a line of sample text, so what you see is
what a player sees.

## Using it

**A Text Effect is a colour.** Each effect gets its own exact text colour, and
any text in that colour wears the effect for every player who has your pack.
No plugin is needed.

Under **Use it**, the page gives you that colour ready to copy three ways:

| Line | Where to use it |
| --- | --- |
| **Command** | A `/tellraw` command that prints sample text with the effect |
| **MiniMessage** | A `<#hex>` tag, for Paper and most chat and item plugins |
| **RP Engine** | `<fx:studio:<id>>Hello</fx>`, for item names, messages and chat on a server running [RP Engine](/rp-engine/text-effects) |

**Show in chat** sends you a sample line on the server your pack is synced to
(sent to your server with **Sync** and `/rp sync <code>`; see
[Testing on your server](/testing/plugin)).

To make Text Effects by hand in a server's config instead, see
[Text Effects in RP Engine](/rp-engine/text-effects).

## Limits

- **Only text on the screen.** Signs, name tags and text displays in the world
  keep the plain colour, which is very nearly white.
- **32 per pack, shared** with 2D and 3D [Shaders](/shaders).
- **A colour code inside the text ends the effect.** Bold and italic are fine.
- **It needs your pack.** Players without it see near-white text.
- **One text shader per screen.** If a player's game also has another pack
  that replaces the text shader on top of yours, only one of the two draws.
