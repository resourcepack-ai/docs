# Icons

An icon is a small picture tied to a text character. Put that character
anywhere Minecraft draws text (chat, signs, books, item names, scoreboards,
holograms) and your picture appears in its place. It's how servers show rank
badges, coins, custom emoji and little symbols inside messages.

![Icons made in Studio, used in chat](/images/icons.webp)

## Making one

Open a pack, press **Add asset** and pick **Icon**. For the badge in front of a
player's name, set **Type** to **Rank tag** instead: see
[Rank Tags](/rank-tags).

- **Generate**: describe it ("a gold coin", "a crossed sword and shield") and
  finish it in the pixel editor.
- **Blank**: draw it yourself.
- **Upload**: bring a PNG. It keeps its shape: set a width or a height (or pick
  a preset) and the other follows the picture. A picture 32 pixels tall or less
  starts at its own size.

Small pixel art is unforgiving: below about 6 pixels of real detail, an icon
stops reading. Get the silhouette right first.

### Which size to pick

| Size | How it sits in text |
| --- | --- |
| **8px** | Fits inside one line of text. The only size guaranteed not to overlap |
| **12px** | Blank and Upload only. A readable chat icon that sits on the line |
| **16px** | The default for Blank and Upload. Overlaps the lines above and below a little |
| **32px** | The default for Generate. A big icon that overlaps neighbouring lines, like a large emoji |
| **64px** and **128px** | Generate only. For GUIs, HUDs and screens rather than chat |
| **Custom** | Blank and Upload only: any width and height, up to 256 |

A generated icon is always square: 8, 16, 32, 64 or 128 pixels. An 8px one has
very little room and most come out rough, so use 16 or 32 for anything with
detail. For a wide or tall icon, or a 12px one, draw it from blank or upload
one.

Minecraft's lines of text are about 9 pixels apart and the game doesn't make
room for taller icons, so 16 and 32 overlap on purpose. Use 8 or 12 when an
icon has to stay inside its line.

### Choosing from 4 versions

Every Icon you generate from a description is drawn 4 times, and Studio
picks the best one to start you off. On a paid plan, the **Versions** card on
its page shows all 4: hover over one to preview it, and click it to use it
instead. Switching is free, and the one it replaces stays in the Icon's AI
history, so you can always switch back. On the free plan, the card shows that 4
were drawn.

Icons made from a reference picture are drawn once, so they have no
Versions card.

### Which character it uses

Every icon is drawn in place of one text character. Leave **Character** blank
and Studio gives the icon a new character from
Unicode's Private Use Area (`U+E000` to `U+F8FF`), a range no real text uses.
Or type an existing character (`A`, `❤`) to replace it everywhere text is
drawn, for everyone with the pack.

A Private Use character shows as a blank box anywhere without your pack. That's
expected.

## Seeing it in game

On a server running [RP Engine](/testing/plugin), our free plugin, press
**Sync** to send the pack to yourself in game. Then press **Send in-game** on
the icon's page to get it in your chat, or copy the character from the page and
paste it anywhere text appears. Nothing has to be placed or given: an icon works in
every message the moment a player has the pack.

<Callout type="tip">
  On [our test server](/testing/test-server), `/sidebar`, `/title`,
  `/actionbar` and `/bossbar` take any text. Paste an icon into one to see how
  it sits next to real game text.
</Callout>

A plugin sends one like any other text:

```java
//  is the icon's character. Its page in Studio shows yours.
player.sendMessage(Component.text(" Quest complete"));
```

On a server running [RP Engine](/rp-engine), players can also type icons by
name; see [RP Engine icons](/rp-engine/icons).

## Exporting

An icon is two things in the `.zip`:

```
assets/minecraft/textures/font/<name>.png
assets/minecraft/font/default.json
```

The PNG is the picture. `default.json` is the font file that ties each picture
to its character and sets how high it sits on the line. Every icon in the pack
shares it. It adds to the default font rather than replacing it, so ordinary
text is untouched.

<Callout type="note" title="Characters are per pack">
  An icon copied into another pack usually keeps its character, but gets a new
  one if that pack already uses it. Copy the character from the icon's page
  again after moving it.
</Callout>

## On Bedrock

Icons carry over to the `.mcpack`, and the same character shows the same
picture on Bedrock. Two differences:

- **Every icon is about one line of text tall** on Bedrock, whatever size you
  gave it.
- **Bedrock uses part of the same character range for its own button prompts.**
  A pack with icons replaces those, so a controller prompt can show blank for a
  Bedrock player.
