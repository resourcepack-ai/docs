# API overview

The ResourcePack AI API lets your own code do what Studio does to a pack:
create a pack, generate block textures, models, items, armour, GUIs, the HUD,
dialogs, icons, sounds, shaders, VFX and emotes into it, change what's there
with AI, upload files you already have or import a whole resource pack, set
up vehicles and movement groups, rename and delete assets, set the pack's style
guide, push it straight into Minecraft, publish it to servers, and download the
finished `.zip`.

<Callout type="note" title="On a paid plan">
  API keys are available on any paid plan. Calls spend the same AI Credits the
  app does. There's no separate API pricing and no per-request charge.
</Callout>

## Get a key

<Steps>
  <Step title="Open the Developers page">
    Go to [studio.resourcepack.ai/developers](https://studio.resourcepack.ai/developers)
    and find the **API keys** card. The **MCP keys** card below it is for
    connecting an AI agent (see [MCP server](/api-reference/mcp)). Each kind of
    key only works on its own surface.
  </Step>
  <Step title="Name it and create it">
    The name is only for telling keys apart, so use what it's for: `ci`,
    `my bot`, `laptop`.
  </Step>
  <Step title="Copy it immediately">
    **The key is shown once.** We store only a hash of it, so we can't show it
    again. If you lose it, revoke it and make another.
  </Step>
</Steps>

API keys are `rpai_` followed by 43 random characters (MCP keys start
`rpai_mcp_`). The prefix makes a key that leaks into a commit or log easy to
search for.

Don't confuse these with **Bring Your Own Key** on your account page, which is
a key you give us. These are keys we give your code.

## Authenticate

Send the key as a bearer token:

```bash
curl https://api.resourcepack.ai/v1/packs \
  -H "Authorization: Bearer rpai_YOUR_KEY"
```

That's the only accepted way. Keys in query strings end up in logs and browser
history, so they're refused.

<Callout type="warning" title="A key is your whole account">
  It can read, generate into and export every pack you own or collaborate on,
  and it spends your credits. Keep it server-side: never in a Minecraft plugin,
  a browser bundle, or anything you hand to a player. Revoke it from the same
  card the moment you think it's out, and check its [history](/api-reference/history).
</Callout>

## Rate limits

Each key gets **120 reads** and **30 writes** per rolling minute. A write is
any `POST` (creating a pack, generating, uploading, importing) plus export.
Over budget answers `429` with a `Retry-After` header. Credits still apply: a
generation you can't afford is refused with `402`. See
[Rate limits](/api-reference/rate-limits).

## What's not here

The API doesn't edit pixels or geometry by hand, change a pack's own settings
or its collaborators, or make skins. Those are in Studio. If you need one of them from code, tell us in
[Discord](https://resourcepack.ai/discord).
