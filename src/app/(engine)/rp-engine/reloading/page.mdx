# Reloading

```
/rp reload
```

Re-reads every pack and `config.yml`, rebuilds every bundle, and sends the new
pack to everybody holding one. Players see a short reload of their resource
pack.

## A pack is replaced whole

A reload does not patch what changed: it loads everything again from the
folder. Something you deleted stops existing straight away.

On a large pack this takes seconds. Run it while you are authoring; there is
no reason to put it on a timer.

## Mistakes do not stop it

A bad definition is skipped and the rest of the pack loads. A broken pack
never stops another one loading.

The console lists every problem in one go, with the file and the ID, so you
can fix them all before reloading again.

## What survives

**Everything already placed in the world.** Placed models are ordinary
entities saved with the chunk and tagged with their ID, so they survive a
reload, a restart, and copying the world to another server.

Deleting a pack therefore does not delete what was built with it. Those models
stay where they are with no art until the pack comes back.

## Orphans

An orphan is a placed model whose content no longer exists.

```
/rp models [radius]   placed models near you, orphans marked
/rp purge [radius]    remove the orphans near you, and nothing else
```

The radius is in blocks: 16 if you leave it out, 128 at most. `/rp purge`
never removes a model whose pack still defines it.
