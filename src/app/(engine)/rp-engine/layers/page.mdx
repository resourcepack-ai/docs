# Layers and masks

A layer lets one animation play on top of another, such as a wave over a walk.
A mask limits an animation to part of a model, such as the upper body. Both
are set per animation in the item's `place:` block, next to the
[playback settings](/rp-engine/playback):

```yaml
  place:
    animations:
      walk:  { mode: loop, layer: 0 }
      wave:  { mode: once, layer: 1, bones: [torso], blend: 0.2 }
```

## Layers

`layer: 0` is the base: a walk cycle or an idle. Only one base animation plays
at a time, and starting another replaces it.

Anything on layer 1 or higher plays on top of whatever is running, so a wave on
layer 1 plays over the walk rather than replacing it. Each layer holds one
animation, so waving again replaces the first wave and leaves the walk alone.

Plugins and commands play an animation by name; the layer comes from these
settings, so nothing that plays it needs to know about layers.

## Masks

`bones:` limits the animation to the bones you name and everything attached
under them. `bones: [torso]` moves the torso and the arms and head hanging off
it, which is what "upper body only" usually means. Name the parent bone rather
than listing every limb. Bone names are whatever you called them in
Blockbench.

A bone is either in the mask or not. There is no partial strength per bone; if
you need the shoulder at half strength and the hand at full, author that into
the animation itself.

## Weight

`weight:` (0 to 1) scales how far the animation moves what it touches. Half a
wave is a smaller wave. Rotation and position are scaled toward zero and scale
toward 1, so a bone scaled to 2 at half weight ends up at 1.5.
