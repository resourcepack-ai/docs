# RP Engine

RP Engine is a plugin for Spigot and Paper servers (Minecraft 1.19.4 and newer)
that adds things vanilla Minecraft does not have: swords with their own
models, chairs you can sit in, emotes, custom sounds, icons in chat, artwork
behind your menus, recipes, mobs, vehicles and liquids.

![Models placed by RP Engine](/images/models.webp)

You describe each one in a few lines of YAML in a folder on your server. The
plugin turns that folder into a resource pack (the zip of textures, models and
sounds a Minecraft client downloads), sends it to every player who joins, and
makes the content work on the server side.

You never build or upload a zip yourself. The plugin builds the pack and
serves it.

<Callout type="note" title="Studio is optional">
  RP Engine works entirely from files on disk. [Studio](https://studio.resourcepack.ai)
  makes the art with AI and can push it straight to a running server, which is
  faster, but you never need it.
</Callout>

## What it can hold

| Content | What it is |
|---|---|
| [Custom blocks](/rp-engine/blocks) | A block you place, mine and stand on |
| [Items](/rp-engine/items) | Sprites or 3D models, wearable as [armour](/rp-engine/armour), with real [vanilla stats](/rp-engine/stats) |
| [Actions](/rp-engine/actions) | What an item does when it is used, hit with, and so on |
| [Models](/rp-engine/models) | Put down, [sat on](/rp-engine/placement-options), [animated](/rp-engine/animation), [worn by a mob](/rp-engine/mobs) |
| [Emotes](/rp-engine/emotes) | Worn or performed, alone or with other players |
| [Sounds](/rp-engine/sounds) | Real sound events, with subtitles |
| [Icons](/rp-engine/icons) | Pictures that behave like letters, anywhere text shows |
| [GUIs](/rp-engine/screens) | A picture drawn behind a chest-style menu |
| [HUD](/rp-engine/hud) | Overlays drawn over the game screen |
| [Recipes](/rp-engine/recipes) | Crafting, cooking, stonecutting, smithing, brewing, anvils |
| [Entities](/rp-engine/entities) | A real mob wearing a model |
| [Vehicles](/rp-engine/vehicles) | Cars, boats and aircraft players drive |
| [Liquids](/rp-engine/liquids) | Pools with their own rules |

## Two ideas worth knowing

**One ID for everything.** `mypack:ruby` is the item, the path to its model
and what is stored on the item stack. There are no numbers to allocate or keep
in sync. If you refer to content from another plugin's config, store the ID.
See [IDs and namespaces](/rp-engine/ids).

**Players can hold several packs at once.** Content is built into
[bundles](/rp-engine/bundles), and on 1.20.3 and newer a player can hold more
than one, so a lobby pack and a dungeon pack can be separate. Swapping back to
a bundle a player already has is instant.
