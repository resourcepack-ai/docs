# Entities

A custom entity is a real Minecraft mob that wears one of your models: a temple
guard, a boss, a pet. It keeps the AI, loot and hitbox of the mob it's built
on, so it fights, wanders and dies like that mob, but looks like your model.

```yaml
# entities/guards.yml
guard:
  type: ZOMBIE           # required; choose it for behaviour, the looks are replaced
  model: mypack:guard    # an item id, whose model it wears
  name: "&cTemple Guard"
  health: 40
  scale: 1.2
  silent: false
  tags: [temple, boss]
```

`model:` is an **item** id, not a file name. The model itself is an item like
any other, so the guard above needs one in `items/` as well, wearing the
Blockbench file you saved to `assets/models/guard.bbmodel`:

```yaml
# items/guard.yml
guard:
  material: PAPER
  model: guard           # assets/models/guard.bbmodel
```

Without that item the mob spawns as a plain zombie, and `/rp reload` says so.

`/rp spawn mypack:guard` spawns one where you stand. `/rp entities` lists them.

| Field | Default | What it does |
|---|---|---|
| `type` | required | The vanilla mob it is. Must be a mob that can be spawned |
| `model` | none | An item id; the mob wears that item's model |
| `name` | none | Its name, with `&` colour codes |
| `health` | the mob's own | Up to 1024 |
| `scale` | 1 | How big the model is drawn, 0.1 to 16. The mob's hitbox is unchanged |
| `silent` | `false` | Mutes the mob's own sounds |
| `tags` | none | Scoreboard tags added when it spawns |

## Choosing the type

Pick `type` for how it should behave, not how it should look. A zombie hunts
players and burns in daylight, a villager wanders and runs away, an armour
stand does nothing at all. Every other plugin sees it as that vanilla mob.

`tags` are how the rest of your server finds these mobs: `@e[tag=boss]` in a
command block, a MythicMobs condition, or a `/kill` that clears one kind and
not another.

## How the model is worn

The model rides on the mob, and the mob's own body is made invisible rather
than removed, so players hit it where it appears to be. Custom entities never
despawn (a despawned mob would leave its model standing in an empty field).

A model's bones can do more than be drawn: turn a head towards the mob's
target, give a wing its own hitbox, add a seat. See [Bones](/rp-engine/bones).

<Callout type="note" title="Somebody else's mob">
  To put a model on a mob another plugin spawned, like a MythicMobs boss or a
  Citizens NPC, see [Putting a model on a mob](/rp-engine/mobs). That page
  dresses an existing mob; this one creates a new one.
</Callout>
