# Placing a model

A placed model is furniture, decoration or a prop: a chair, a lamp, a statue.
You give an item a `place:` block, and right-clicking a block with that item
puts the model down in the world at its true size. It is drawn by a **display
entity** (an invisible entity whose only job is to show a model), not a block
and not an armour stand wearing a helmet.

```
content/mypack/
  items/furniture.yml
  assets/models/chair.bbmodel
```

```yaml
chair:
  material: PAPER
  model: chair           # assets/models/chair.bbmodel
  name: "&eOak Chair"
  place:
    facing: cardinal     # cardinal | diagonal | free | fixed
    scale: 1.0
    solid: false         # true gives it something to walk into
    vehicle-collision: true  # false lets vehicles drive through it
    seat: 0.5            # sit on it, this far above its base. 0 is no seat
    light: 0             # 0-15, what it gives off
    surface: floor       # floor | wall | ceiling | any
    drop: mypack:shard   # what breaking it gives back. Default: itself
  permission: mypack.chair
```

`/rp give mypack:chair` gives you the item. Right-click the ground to place it,
and punch it to take it back. Breaking it in creative mode gives nothing back.

The item and the placed model share one ID (`mypack:chair`), so there is no
separate "placed" entry to keep in step with the item.

## Size

A placed model is the size the Blockbench file says it is: 16 model units to
the block, so a model built to y=32 stands two blocks tall. If a lamp looks a
block tall when you built it three, check the cube coordinates in the model.
`scale:` multiplies the size, for when you want the same model in two sizes.

## Which way it faces

| `facing:` | How it turns |
|---|---|
| `cardinal` | North, east, south or west, like a placed furnace. The default |
| `diagonal` | Eight directions |
| `free` | Exactly the way you were looking |
| `fixed` | Always the same way, for something with no front |

## The hitbox

The hitbox (what you can punch) is measured off the model, so a two-block
statue can be hit anywhere you can see it. `width:` and `height:`, in blocks,
override it.

A display entity has no collision, so players walk straight through a placed
model. `solid: true` puts an invisible barrier block in the model's own block
space and removes it when the model is broken. That suits a bench, not a rug.
The barrier is one block, whatever shape the model is.

## Vehicles

`vehicle-collision` decides whether [vehicles](/rp-engine/vehicles) are stopped
by the model. It is on by default and separate from `solid:`, which is about
players on foot.

A vehicle is tested against the model's real cubes, not a box round them, and
no blocks are placed for it. You can drive a go-kart between the legs of a
table or under an archway, and a fence stops you along its whole length. Any
placement angle works.

- Turned cubes keep their angle, so a turned slab is a **ramp** a vehicle
  drives up.
- Anything up to a block high is climbed like a kerb, and stairs built from
  stacked cubes are climbed a tread at a time.
- A piece a vehicle can climb also holds it up, so a row of platform models is a
  bridge.

Set `vehicle-collision: false` for things that should have no effect at all: a
road marking, a manhole cover, a decal.

## Furniture that does something

A piece can also be a container, a jukebox, a lamp or door a click switches, a
sofa that joins the pieces beside it, or something that grows into another
piece over time:

```yaml
place:
  storage: { type: chest, rows: 3 }
  jukebox: true
  states:
    - { model: mypack:lamp_on, light: 15 }
  connects: true
  grow: { into: mypack:rose_stage2, after: 2m }
```

See [Working furniture](/rp-engine/furniture) for each of them, and for which
one a click goes to when a piece is several at once.

## Animation

If the `.bbmodel` has keyframes in it, the piece moves. See
[Animation](/rp-engine/animation). Bones can also carry hitboxes and nametags;
see [Bones that do something](/rp-engine/bones).

## Who may place what

- **`permission:`** on the item decides who may use it, which includes placing
  it. Without one, anybody holding it may.
- **WorldGuard**: the `rpengine-place` region flag allows or denies placing and
  breaking models in a region. See [WorldGuard](/rp-engine/worldguard).
- **`ModelPlaceEvent`** is for any other rule, from your own plugin. Cancel it
  and the model is not placed and the item is not used up. See
  [the API](/rp-engine/api).

Placing never replaces a block: the space has to be empty. Right-clicking a
chest, door or other block you can use opens it as normal; sneak to place
against it.

## What is stored

A placed model is two entities saved with the chunk: a display for what you
see and an interaction entity for what you can hit. Nothing is kept in a
separate file or database, so a model survives a restart and moves with a
world you copy.

If a pack stops declaring a model, everything already placed stays where it is
with no art until the pack declares it again. `/rp models` lists the models
around you and marks these orphans, and `/rp purge` removes the orphans and
nothing else.
