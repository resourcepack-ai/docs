# HUD overlays

An overlay is drawn over the game rather than behind a window.

```yaml
# huds/overlays.yml
mana:
  slot: action_bar       # action_bar | boss_bar
  height: 64
  ascent: 32
```

`/rp hud mypack:mana` shows one; `/rp hud clear` takes it away.

## The two slots

Both are places the game already draws text somewhere fixed, which is the whole
trick: an overlay is a glyph placed into that text with enough negative space
around it to land where you drew it.

| Slot | Where it draws |
|---|---|
| `action_bar` | Above the hotbar. Vanilla uses it for item names |
| `boss_bar` | The top of the screen, where a boss health bar goes |

There is no third slot, because there is no third piece of text the game will
draw wherever you ask.

## Height and ascent

`height` is how tall the picture is drawn. `ascent` moves it up the screen from
the slot's baseline — a bigger ascent is higher.

An ascent **greater than the height** is refused by the client and takes the
whole font down with it, so if every icon on your server vanishes at once, this
is the first number to check.

## What it is not

An overlay is a picture, and a picture cannot know anything. A mana bar that
empties is several overlays and something of yours choosing which to show —
RP Engine draws whichever you ask for and has no opinion about mana.

That "something of yours" is usually a scoreboard or menu plugin reading
[a placeholder](/rp-engine/placeholderapi), or your own plugin calling the
[API](/rp-engine/api).

## Shader overlays from Studio

Studio's **Shaders** editor builds overlays from shapes and text. Drag either
on the canvas to position it; text rows move independently. Select an element
in the list when another element covers it. Shape handles resize the shape.

The **Anchors** panel aligns the selected element inside the canvas. Check
several elements to move them together while preserving their spacing.
**Where on screen** sets the whole overlay's screen anchor using nine presets.
These follow the player's window and GUI scale. Drag the blue frame in the
screen preview to adjust the offset, or use **Right** and **Up**.
**Reset to action bar** restores the original position above the hotbar.

Text uses Minecraft's font. A `{name}` placeholder is filled by the server;
changing its value keeps the canvas in place. Preview placeholders show their
names, so their displayed length can differ from a player's actual value.

Push the updated pack after editing. Shader overlays use the action-bar slot;
when several overlays are shown, the most recently shown one is visible.
