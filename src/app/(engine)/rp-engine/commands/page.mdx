# Commands

One command, `/rpengine`, with `/rpe` and `/rp` as aliases — plus `/emote` and
`/emotereply` for players.

**Everything tab-completes**, at every argument. A subcommand you cannot run is
not offered, because completing a command that then refuses is worse than not
completing it.

## Content

| Command | What it does |
|---|---|
| `/rp reload` | Reread the content folder and rebuild every pack |
| `/rp info` | What this server is holding |
| `/rp bundles` | The built packs, with their sizes and hashes |
| `/rp items` | Every custom item |
| `/rp give <id> [player]` | Give one |
| `/rp models` | Placed models near you |
| `/rp purge` | Remove placed models whose content is gone |
| `/rp spawn <id>` | Spawn a custom entity |
| `/rp entities` | Every custom entity |
| `/rp bind <id>` | Put a model on the mob you are looking at |
| `/rp unbind` | Take it off again |
| `/rp recipes` | Every recipe |

## Sound, text and interface

| Command | What it does |
|---|---|
| `/rp sounds` | Every custom sound |
| `/rp sound <id> [player]` | Play one |
| `/rp icons` | Every icon, with the character it became |
| `/rp say <text>` | Send yourself text, with `:pack:icon:` resolved |
| `/rp screens` | Every screen and HUD |
| `/rp screen <id> [player]` | Open one |
| `/rp hud <id\|clear> [player]` | Draw an overlay, or clear it |

## Liquids

| Command | What it does |
|---|---|
| `/rp liquid corner` | Mark one corner of a pool |
| `/rp liquid fill <id>` | Make the box between it and where you stand that liquid |
| `/rp liquid clear` | Remove the pool you are in |
| `/rp liquid list` | Every pool, per world |

## Studio

| Command | What it does |
|---|---|
| `/rp sync <code>` | Pair with a pack open in Studio |
| `/rp sync add <player>` | Ask somebody onto your sync |
| `/rp sync accept` / `deny` | Answer that |
| `/rp sync who` | Who is on it |
| `/rp sync remove <player>` | Take somebody off, and the pack off them |
| `/rp sync leave` | Leave somebody else's |
| `/rp sync stop` | End yours, for everybody |
| `/rp push` | Re-send this server's pack to yourself |
| `/rp distribute <code>` | Serve a published pack to everybody who joins. `off` stops |

## Emotes

| Command | What it does |
|---|---|
| `/emote <name>` | Perform it, or wear it if it is a movement set |
| `/emote <name> <player...>` | With a cast. They are asked first |
| `/emote stop` | Stop yours, and everybody in it with you |
| `/emotereply accept` / `deny` | Answer an invitation |
| `/rp emotes` | Every emote the server holds |

## Permissions

One node per command. See [Permissions](/rp-engine/permissions).
